# Installation de Patenteasy 0.3.7

## Windows

1. Sauvegardez vos données.
2. Fermez Patenteasy s'il est ouvert.
3. Lancez `Patenteasy-Windows-0.3.7-Installation.exe`.
4. Suivez l'installation puis ouvrez Patenteasy depuis le raccourci créé.

Patenteasy Windows utilise une interface native PySide6/Qt. L'installation utilisateur conserve ses données dans `%LOCALAPPDATA%\PatenteasyLocal\data`.

## Android

1. Sauvegardez vos données.
2. Installez `Patenteasy-Android-0.3.7.apk` par-dessus la version existante.
3. Ne désinstallez pas l'ancienne application avant la mise à jour, afin de ne pas supprimer ses données locales.

Android 8 ou plus récent est requis.

## Important

Les éditions Windows et Android sont locales et indépendantes : il n'y a pas de synchronisation automatique entre les deux.

Les clés de signature, mots de passe, sauvegardes privées et données utilisateur ne doivent jamais être ajoutés au dépôt Git.
