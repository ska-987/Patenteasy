# Patenteasy 0.3.7 — bêta-test

Développeur : **ska_987**

## Installation et test

Windows : fermez Patenteasy puis lancez `Patenteasy-Windows-0.3.7-Installation.exe`.

Android : installez `Patenteasy-Android-0.3.7.apk` par-dessus la version précédente. Ne désinstallez pas l'application avant la mise à jour.

Windows 64 bits et Android 8 ou plus récent sont pris en charge pour cette bêta.

Les deux applications sont autonomes et ne synchronisent pas automatiquement leurs données.

## Parcours conseillé

1. Vérifier la version 0.3.7 et les icônes sur Windows et Android.
2. Tester un compte administrateur puis un compte utilisateur.
3. Faire une sauvegarde et une restauration sur des données de test.
4. Créer un client, un devis, une facture et un paiement partiel.
5. Tester une relance de facture.
6. Vérifier les recherches, le thème sombre et l'export CSV administrateur.
7. Vérifier l'alerte de sauvegarde lorsque l'emplacement n'est plus accessible.
8. Tester la mise à jour depuis une installation précédente sur un appareil de test.

## Vérifications de la livraison

- tests Windows/Python ;
- tests Android du chiffrement, des signatures et du modèle métier ;
- APK signée avec le certificat de production existant ;
- contrôles d'intégrité des archives et de l'installateur.

Les tests sur un vrai PC Windows et un vrai téléphone restent indispensables avant diffusion générale.
