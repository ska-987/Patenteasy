# Patenteasy bêta 0.4.2 — règlements partiels

Windows et Android : les factures et PDF affichent les règlements reçus, leur détail et le reste à régler. Le total émis n’est pas recalculé. Les anciens PDF doivent être réexportés.

Installer par-dessus la version existante après sauvegarde. Android utilise le certificat original et le versionCode 11. L’installation et le PDF natif doivent être confirmés sur téléphone.

Le workflow construit, contrôle et, si les secrets sont configurés, signe puis publie les applications. Le catalogue signé est envoyé en dernier après vérification des deux téléchargements. Sans secrets, aucune publication n’est effectuée ; utiliser le paquet de publication depuis le PC éditeur avec la clé de catalogue originale.
